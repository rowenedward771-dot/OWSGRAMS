# Owsgram

Owsgram is a web application designed to provide a platform for sharing and discovering content. This project includes a clean and modern user interface built with HTML, CSS, and JavaScript.

## Project Structure

```
owsgram
├── index.html        # Main entry point of the web application
├── styles.css        # CSS styles for the application
├── scripts
│   └── app.js       # JavaScript code for interactivity
├── templates
│   └── base.html    # Base layout template for other HTML pages
├── .nojekyll         # Prevents Jekyll processing on GitHub Pages
└── README.md         # Project documentation
```

## Features

- Responsive design using Tailwind CSS
- User authentication and profile management
- Flash messages for user feedback
- Share functionality for posts

## Setup Instructions

1. Clone the repository to your local machine:
   ```
   git clone https://github.com/<username>/<repository-name>.git
   ```
2. Navigate to the project directory:
   ```
   cd <repository-name>
   ```
3. Open `index.html` in your web browser to view the application.

## Deployment on GitHub Pages

To deploy this project on GitHub Pages, follow these steps:

1. Create a new repository on GitHub.
2. Clone the repository to your local machine.
3. Copy the project files into the cloned repository folder.
4. Commit the changes:
   ```
   git add .
   git commit -m "Initial commit"
   ```
5. Push the changes to GitHub:
   ```
   git push origin main
   ```
6. Go to the repository settings on GitHub, scroll down to the "GitHub Pages" section, and select the branch (usually `main` or `master`) to publish from.
7. Your site will be available at `https://<username>.github.io/<repository-name>/`.
